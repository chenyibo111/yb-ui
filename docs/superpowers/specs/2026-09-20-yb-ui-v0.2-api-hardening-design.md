# YB UI v0.2 API 加固设计

## 背景与目标

YB UI v0.1 已交付 33 个基础组件、公开 npm 包、文档站、Storybook 和验证流程。当前组件目录与文档覆盖完整，但许多组件仍是轻量原语封装，公开 API 尚不足以覆盖企业后台的常见状态与交互。

v0.2 的目标不是复刻 Ant Design 的完整组件清单，而是建设一个覆盖约 80% 企业后台场景的精简成熟 React 组件库。成功标准是高频流程可用一致的 YB API 实现，并且调用者不需要依赖组件内部 CSS 或底层第三方库。

## 非目标

- 不追求 Ant Design 全量 API 或组件数量对齐。
- 不在首批实现 Upload、Tree、Transfer、富文本、图表、全套 Layout、时间选择、表格虚拟滚动、列拖拽或树表。
- 不在核心 `@chenyibo111/ui` 中绑定某一种表单状态或校验框架。
- 不在 v0.2 中交付深色主题；现有 Token 架构继续保持深色就绪。
- 不导入或依赖任何业务项目代码。

## 架构原则

YB UI 采用混合模式：简单语义与样式原语由组件库维护；复杂交互基于成熟底层库封装。使用者只消费 YB 的公开 API 和类型，不应接触 Radix、TanStack Table 或 react-day-picker 的实现类型。

| 范围 | 实现原则 |
| --- | --- |
| Button、Input、Field、Dialog 等基础原语 | YB 维护语义、样式、状态和可访问性契约。 |
| Dialog、Select、Toast 等复杂交互 | 继续使用 Radix 作为内部行为原语。 |
| DatePicker 与 DateRangePicker | 基于 react-day-picker，YB 提供严格、稳定的值与回调类型。 |
| DataTable | 基于 TanStack Table，YB 定义列、查询和选择模型。 |
| React Hook Form 集成 | 以单独的可选适配包交付，不侵入核心 UI 包。 |

## 统一 API 契约

所有组件遵循一致的公开约定，并只在语义适用时暴露对应能力。

- 交互组件支持适用的 `size`、`disabled`、`className` 和 `style`。
- 输入与选择组件以 `status="error" | "warning"` 表达校验视觉状态，并可由 `Field` 的错误信息关联。
- 原生输入类组件保留 React 原生模型：`value`、`defaultValue`、`onChange`。
- 组合选择类组件采用 `value`、`defaultValue`、`onValueChange`；旧 API 保持兼容，并在文档中标记迁移方向。
- `loading` 只用于存在异步等待状态的操作或数据组件。
- 复杂组件通过稳定的 `classNames`、`styles` 槽位开放必要的样式扩展点；消费者不得依赖 `.yb-*` 内部类。
- 公开 TypeScript 类型只包含 YB 定义的领域类型，不透出底层库的主类型。
- v0.2 所有 API 变更必须向后兼容。改名以新增别名、弃用提示和迁移文档处理，不在 minor 版本中移除旧用法。

## 动效系统

YB UI 使用克制的企业后台动效语言：状态反馈为 120–160ms，浮层进入/退出为 180–240ms；进入使用减速缓动，退出使用加速缓动。浮层进入可以淡入、缩放 `0.98 → 1` 或沿其来源方向位移 4–8px；禁止弹簧、回弹和大幅位移动画。

`@chenyibo111/tokens` 新增公开 Motion Token：`motion-duration-fast`、`motion-duration-normal`、`motion-duration-slow`、`motion-ease-enter`、`motion-ease-exit`、`motion-distance-sm` 与 `motion-distance-md`。组件样式只消费这些 Token；`yb-*` keyframe 名称仍是内部实现，不构成消费者 API。

Button、Input、Textarea、Tabs 等使用短暂的颜色、边框、阴影或透明度过渡。Dialog、Drawer、Popover、Select、DropdownMenu、Tooltip 和 Toast 使用 Radix 的 `data-state`、`data-side` 或 `data-swipe` 属性驱动进入和退出动画。动画不能改变文档流尺寸或拦截键盘焦点。

所有组件必须遵守 `prefers-reduced-motion: reduce`：将 transition 和 animation 持续时间降至 1ms，取消位移与缩放。动效不增加公开的动画名称或必须由消费者手动关闭的 props。

## v0.2 组件范围

### 输入与字段

`Input` 和 `Textarea` 增加 `size`、`status`、`clearable`、前后缀槽位、长度限制与可选计数展示。它们保持原生事件模型和可转发 ref。

`Field` 增加状态、帮助信息与稳定样式槽位。新增轻量 `Form`，仅负责表单布局、提交语义、错误摘要和首个错误定位；它不拥有字段值或校验规则。

### 选择与日期

`Select` 保持固定单选的清晰语义。新增 `Combobox` 承担搜索、异步选项、多选、清除与空状态，避免把自由输入与固定选择混入同一组件。

`DatePicker` 统一受控和非受控模型，补齐 `disabledDate`、`presets`、`format`、`placeholder` 与 `clearable`。范围选择以新的 `DateRangePicker` 独立公开，而不是把多种模式放在同一高层 API 中。

### 数据展示

现有 `Table` 始终是语义化展示原语。新增 `DataTable`，负责企业后台常见的数据工作流：列定义、排序、筛选、行选择、加载、空态、受控分页和服务端查询。

`Pagination` 补齐 `total`、`pageSize`、页码省略、页面大小切换与受控查询回调。DataTable 与 Pagination 共用 YB 的查询模型，而不把 TanStack Table 的 state 对象暴露给消费者。

### 应用级反馈

`ToastProvider` 增加 `useToast()` 队列服务，支持规范化的成功、错误、警告、信息、操作按钮和关闭行为。新增 `ConfirmDialog`，提供不可逆操作所需的标题、描述、确认/取消操作和危险状态语义。

## 包与依赖边界

`@chenyibo111/ui` 承载核心组件以及内部依赖的 Radix、react-day-picker、TanStack Table 封装。用户仍然只需从 YB 的公开入口导入。

新增 `@chenyibo111/react-hook-form` 作为可选适配包：它依赖 `@chenyibo111/ui`，并将 `react-hook-form` 声明为 peer dependency。该包提供字段控制、错误映射和可访问性关联，避免核心包与第三方表单框架耦合。

DataTable 的公开类型包含 YB 自己的 `DataTableColumn`、`DataTableQuery`、`DataTablePagination`、`DataTableSorter`、`DataTableFilter` 和 `DataTableRowSelection`。内部可映射至 TanStack，但不 re-export `ColumnDef` 或其状态类型。

## 状态与数据流

- 原语组件默认同时支持受控与非受控模式，遵循 React 的值与回调约定。
- Form 通过 props 和回调表达提交、错误摘要与布局；应用或适配包拥有字段状态和校验。
- DataTable 使用受控查询对象和变更回调与服务端衔接；数据加载、错误和空态由明确 props 表达。
- Toast 是唯一由 Provider 管理全局队列的能力；其余组件不引入全局状态。

## 质量、文档与发布

每个新增或增强的 API 必须具备：

- 受控与非受控行为测试；
- 键盘、焦点与可访问名称测试；
- loading、错误、禁用与空状态测试；
- Storybook 的核心状态故事；
- Docs 中的可运行示例、API 表和迁移说明；
- 关键交互的 axe 无障碍断言与视觉回归基线。
- 浮层的进入、退出和减少动态效果模式测试。

CI 继续运行 `pnpm verify`、Docs 测试与构建、Storybook 构建，并增加关键组件的无障碍与视觉回归检查。每个公开包变更通过 Changesets 生成兼容的 v0.2 版本；仅在实现完成后发布。

## 实施顺序

1. 建立统一 API 类型、弃用策略、样式槽位和测试基础设施。
2. 建立 Motion Token、克制动效与减少动态效果契约。
3. 加固 Input、Textarea、Field、Form、Select 与 Combobox。
4. 加固 DatePicker、DateRangePicker 与 Pagination。
5. 建立 DataTable 与 TanStack 内部适配层。
6. 建立 `useToast`、ConfirmDialog 和 React Hook Form 适配包。
7. 补齐 Docs、Storybook、迁移指南、无障碍与视觉回归，并发布 v0.2。
