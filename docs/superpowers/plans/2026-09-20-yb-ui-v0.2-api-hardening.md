# YB UI v0.2 API 加固 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 YB UI 从文档完整的基础原语库加固为覆盖约 80% 企业后台高频流程的、API 一致且向后兼容的 React 组件库。

**Architecture:** 核心 `@chenyibo111/ui` 保持轻量的可访问原语，并对 Input、选择、日期、表单、数据表格与反馈提供稳定高层 API。Motion Token 定义克制的状态与浮层动效，并统一遵守减少动态效果偏好。复杂行为内部封装 Radix、react-day-picker 和 TanStack Table，公开类型不泄露底层库；React Hook Form 通过独立的可选适配包集成。

**Tech Stack:** React 19、TypeScript、Radix UI、react-day-picker、TanStack Table v8、React Hook Form、Vitest、Testing Library、vitest-axe、Playwright、Storybook 9、tsup、Changesets。

**Spec:** `docs/superpowers/specs/2026-09-20-yb-ui-v0.2-api-hardening-design.md`

## Global Constraints

- 工作目录为 `D:\AI\yb-ui` 的 `main` 分支；用户已授权在当前任务中按批次直接提交与推送。
- 仅依赖 YB UI 的公开 API；不导入任何业务项目代码或样式。
- v0.2 只新增兼容 API；已有 v0.1 导出必须继续可用。改名使用别名和 JSDoc `@deprecated`。
- 简单交互保持自研语义；复杂交互内部可依赖 Radix、react-day-picker、TanStack Table，但禁止导出它们的领域类型。
- 所有可见文案使用中文；Docs 页面继续使用稳定英文 URL。
- 首期仍只交付浅色主题，全部新增颜色通过 `--yb-*` Token，不硬编码颜色值。
- 动效时长、缓动和位移必须通过公开 Motion Token；禁止将 `yb-*` keyframe 名称作为公开 API，且所有动画必须遵守 `prefers-reduced-motion: reduce`。
- 每项行为变更先写失败的 Vitest/Testing Library 测试；新 API 必须拥有受控/非受控、键盘、加载/错误/空态测试。
- 每个任务完成后运行对应定向测试；每个提交前运行 `pnpm verify`、`pnpm build-docs`、`pnpm build-storybook`、`git diff --check`。
- 新增公开包或公开 API 后创建 Changeset，但在用户明确要求前不运行发布工作流。

## Review Focus

- 旧的组合式 `<Select><SelectTrigger />…</Select>` 必须继续打开并选择值；Task 4 的兼容测试固定此行为。
- 受控 Input、Combobox、DatePicker、DataTable 的 UI 必须仅由最新 props 驱动；Task 2、4、5、6 各自覆盖父组件更新值。
- `clearable` 不得吞掉键盘焦点、只读值或禁用状态；Task 2 与 Task 5 对清空操作及禁用状态断言。
- DataTable 的服务端分页/排序不得在本地再次改变数据顺序；Task 6 覆盖 `manual` 查询回调与加载空态。
- Toast 队列关闭一个项目时不得误删相邻通知，ConfirmDialog 取消不得触发确认回调；Task 7 覆盖队列 ID 与取消路径。
- 用户启用减少动态效果时，浮层仍可打开/关闭且计算样式不包含位移或超过 1ms 的动画；Task 9 覆盖这一媒体偏好。
