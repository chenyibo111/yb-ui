首期仅交付钴蓝脉冲浅色主题，因此界面不提供主题切换控件。所有组件已基于语义化 CSS Variables 消费颜色、圆角、阴影和间距，主题切换不需要改变组件 API。

## 深色主题就绪

令牌样式已预留 `.dark` 作用域。后续补齐深色数值后，只需在应用根节点添加该类名，即可覆盖相同语义令牌：

```tsx
<html className="dark">
  <body>{children}</body>
</html>
```

在深色主题实际发布前，请继续使用浅色令牌，不要在业务代码中为“未来深色模式”建立第二套颜色判断。

## 扩展原则

- 新增主题时保持令牌名称不变，仅替换值。
- 组件只依赖语义令牌，禁止把主题选择写进组件分支。
- 主题偏好、持久化与自动切换属于应用层能力，后续按项目需求接入。
