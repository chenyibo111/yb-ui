---
title: 色彩
description: 钴蓝脉冲浅色系统的语义化颜色令牌。
---

YB UI 使用语义令牌表达界面目的，而不是在业务页面写入具体颜色值。首期主题为浅色钴蓝脉冲：以高饱和钴蓝作为主要操作与焦点色。

## 基础表面

| 用途 | 令牌 | 说明 |
| --- | --- | --- |
| 页面背景 | `--yb-background` | 应用与文档的底层表面。 |
| 内容卡片 | `--yb-card` | 分组内容与悬浮容器。 |
| 主要文本 | `--yb-foreground` | 标题与正文。 |
| 次要文本 | `--yb-muted-foreground` | 说明、占位和辅助信息。 |
| 边框 | `--yb-border` | 分隔与控件边界。 |

## 状态与操作

| 用途 | 令牌 | 说明 |
| --- | --- | --- |
| 主要操作 | `--yb-primary` | 主按钮、已选状态与焦点环。 |
| 次要操作 | `--yb-secondary` | 低强调度的次级操作。 |
| 危险操作 | `--yb-destructive` | 删除、不可逆确认与高风险反馈。 |
| 成功反馈 | `--yb-success` | 成功完成状态。 |
| 警告反馈 | `--yb-warning` | 需要关注但不阻断的状态。 |
| 信息反馈 | `--yb-info` | 中性提示与说明。 |

## 使用方式

优先使用组件内置的变体；只有自定义业务区域才直接消费令牌。

```css
.project-summary {
  background: var(--yb-card);
  border: 1px solid var(--yb-border);
  color: var(--yb-foreground);
}
```

不要用蓝色来猜测“主要操作”，也不要用红色来猜测“危险操作”；使用语义名称可以让未来主题替换保持稳定。
