---
title: 间距与布局
description: 用一致的间距刻度、Stack 与 Grid 组织页面结构。
---

YB UI 的间距令牌以四像素为基础：`--yb-space-1` 到 `--yb-space-10`。组件的 `gap` 属性直接使用相同刻度，避免在页面中散落任意数值。

## 间距刻度

| 刻度 | 值 | 常见场景 |
| --- | --- | --- |
| `1` | 4px | 紧凑图标与文字。 |
| `2` | 8px | 控件内元素。 |
| `3` | 12px | 常规表单项与列表。 |
| `4` | 16px | 卡片内容与区域内距。 |
| `6` | 24px | 区域间距。 |
| `8` | 32px | 页面主区块。 |

## Stack

`Stack` 适合纵向或横向排列的线性内容。通过 `direction`、`gap`、`align` 与 `justify` 描述布局意图。

```tsx
import { Button, Stack, Text } from "@chenyibo111/ui"

<Stack gap="4">
  <Text>修改尚未保存。</Text>
  <Stack direction="horizontal" gap="2">
    <Button>保存</Button>
    <Button variant="secondary">取消</Button>
  </Stack>
</Stack>
```

## Grid

`Grid` 用于重复卡片或多列信息，以 `columns` 和 `gap` 保持稳定节奏。

```tsx
import { Card, Grid } from "@chenyibo111/ui"

<Grid columns={3} gap="4">
  <Card>项目 A</Card>
  <Card>项目 B</Card>
  <Card>项目 C</Card>
</Grid>
```
