`Input` 保留原生 `<input>` 的属性与事件，适合单行信息录入。需要标签、说明或错误消息时，请与 `Field` 组合。

## 表单集成

`Input` 使用标准 ref、`value`、`defaultValue`、`onChange` 和原生属性，因此可直接与 React Hook Form、Formik 或项目内校验方案组合。业务代码负责校验时机与错误文案，将最终错误传给 `Field` 即可。
