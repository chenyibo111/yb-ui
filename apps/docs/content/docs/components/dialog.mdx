  DialogDescription, DialogTitle, DialogTrigger,

  <DialogTrigger asChild>
    <Button variant="destructive">删除项目</Button>
  </DialogTrigger>
  <DialogContent>
    <DialogTitle>确认删除项目？</DialogTitle>

export const formCode = `<Dialog>
  <DialogTrigger asChild><Button>新建项目</Button></DialogTrigger>

    <DialogTitle>新建项目</DialogTitle>
    <DialogDescription>填写名称后即可创建项目。</DialogDescription>
    <Field label="项目名称" required>
      <Input placeholder="例如：设计系统升级" />
    </Field>
  </DialogContent>
</Dialog>`

`Dialog` 由一组可组合的 Radix 原语构成。它适合需要用户停留并完成明确任务的场景；简单提示请使用 Toast 或页面内反馈。

每个对话框都应包含可读的标题与说明，帮助屏幕阅读器和键盘用户理解当前上下文。

## 可访问性

- 打开后焦点会进入对话框，关闭后返回触发元素。
- 始终提供 `DialogTitle`；有说明时提供 `DialogDescription`。
- Esc 和右上角关闭按钮可关闭对话框，同时应保留显式的取消操作。
