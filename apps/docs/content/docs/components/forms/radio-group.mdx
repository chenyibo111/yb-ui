`RadioGroup` 用于固定、数量较少且必须互斥的选项。选项很多、需要搜索或需要自定义弹层时，应使用 `Select`。

## 可访问性

- 给单选组提供 `aria-label`，或使用应用层的语义分组标签。
- 每个 `RadioGroupItem` 都需要可读名称；示例使用 `label` 扩大可点击区域。
