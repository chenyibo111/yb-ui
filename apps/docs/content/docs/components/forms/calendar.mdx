## 何时不用

仅需要紧凑触发器和弹出日历时，使用 `DatePicker`。业务系统的工作日、节假日、禁用日期和时区规则应由应用层明确提供。

## 可访问性

- 日历使用本地化的月份与导航文案；默认继承 YB Provider 的中文 locale。
- 明确说明禁用日期的业务原因，避免只以灰色外观表达不可用。
