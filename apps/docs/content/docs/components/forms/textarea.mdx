## 聊天输入与长文本

聊天输入通常需要应用层的自动增高、发送快捷键和明确的发送状态；不要将这些业务行为固化到 `Textarea`。普通长文本可使用合适的 `rows`，并根据页面布局决定是否允许用户调整尺寸。

## 可访问性

- 使用 `Field` 或原生 `label` 提供可见名称。
- 将字符数限制、错误和格式要求以文本传达，而非只依赖颜色或 placeholder。
