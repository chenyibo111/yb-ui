`Switch` 表示打开或关闭一个设置。用户切换后应立即生效或立即显示明确的保存反馈。

## 何时不用

需要在表单提交时统一保存的选择，使用 `Checkbox` 更容易表达“已选中但尚未提交”的状态。

## 可访问性

- 提供可见文本、`aria-label` 或与 `Field` 组合，说明该开关控制什么。
- 不能仅靠颜色区分开启和关闭状态，状态必须可被辅助技术读取。
