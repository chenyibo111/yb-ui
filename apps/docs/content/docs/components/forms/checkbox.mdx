## 何时不用

立即生效的单一设置更适合 `Switch`；不要用复选框模拟一次性危险操作的最终确认。

## 可访问性

- 始终以可点击的 `label` 或 `aria-label` 提供名称。
- 不确定状态只用于表达一组选项的部分选择，不替代业务错误状态。
