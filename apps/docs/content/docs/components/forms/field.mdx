export const fieldCode = `import { Field, Input } from "@chenyibo111/ui"

<Field
  description="请使用公司邮箱，格式如 name@example.com。"
  error="请输入有效的工作邮箱地址。"
  label="工作邮箱"
  required
>
  <Input type="email" />
</Field>`

`Field` 用于补齐原生控件周围的语义信息。它只接受一个表单控件子元素，适合 Input、Textarea、Select 触发器等需要标签和错误说明的场景。

## 何时不用

没有可编辑控件的静态说明、多个独立控件组成的复杂区域，不应套在同一个 `Field` 中；请为每个可校验控件单独建立字段。

## 可访问性

- `label` 会通过 `htmlFor` 关联到控件。
- `description` 和 `error` 会并入 `aria-describedby`；错误信息同时带有 `role="alert"`。
- 校验时机、聚焦第一个错误字段和提交策略由业务表单负责。
