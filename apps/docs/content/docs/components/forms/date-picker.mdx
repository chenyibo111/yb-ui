## 日期值与时区

组件返回的日期值及其序列化、存储、跨时区展示策略由业务应用决定。涉及服务端日期时，应在应用契约中明确日期与时刻的边界，避免仅靠格式化字符串推断时区。

## 可访问性

- 默认中文环境下，触发器名称为“选择日期”；日期范围模式为“选择日期范围”。
- 弹层打开后遵循 Calendar 的键盘导航；Escape 可关闭并回到触发器。
