`Badge` 是紧凑的状态展示，不包含动作行为。它通常与标题、列表项或表格字段一起使用。

## 何时不用

可点击的筛选、切换和菜单操作应使用 Button、Tabs 或其他交互组件；不要让静态 Badge 看起来像按钮。

## 可访问性

- 徽标文本本身必须说明状态；颜色只是辅助。
- 与图标并用时，不要重复同一条文字信息。
