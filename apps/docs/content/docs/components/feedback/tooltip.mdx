Tooltip 为图标按钮和术语补充上下文。它是发现性增强，不承担唯一的信息传达职责。

## 何时不用

不要把必需说明、错误消息或唯一操作名称放进 Tooltip；触摸和键盘用户也必须在不悬停时理解界面。

## 可访问性

- 图标按钮仍必须带有 `aria-label`；Tooltip 不替代它。
- Tooltip 内容应补充而非重复复杂说明，并保持可通过键盘触发元素获得。
