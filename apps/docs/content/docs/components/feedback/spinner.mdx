`Spinner` 适合局部、短时且无法确定进度的操作。提交按钮优先使用 `loading`，它会同时禁用重复提交并提供状态文本。

## 何时不用

可预估或较长的任务应提供实际进度信息；内容区首次加载且几何稳定更重要时使用 Skeleton。

## 可访问性

- `Spinner` 使用 `role="status"` 和必填 `label`。
- Button 的 `loading` 会暴露“正在加载”状态；保留原按钮文案以维持上下文。
