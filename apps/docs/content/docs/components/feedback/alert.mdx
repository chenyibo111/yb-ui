<Alert variant="destructive">

  <AlertDescription>继续前请确认该项目不再需要保留。</AlertDescription>
</Alert>`

`Alert` 用于页面内需要持续可见的反馈。它适合解释后果、指出下一步，或承载需要恢复操作的错误。

## 何时不用

短暂确认可以使用 Toast；不应把会立即消失的提示作为用户修复错误的唯一依据。

## 可访问性

- `destructive` 自动使用 `role="alert"`；其他变体使用 `role="status"`。
- 不要只以颜色表达状态，标题和说明应完整传达风险与操作。
