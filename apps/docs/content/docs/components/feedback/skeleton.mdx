`Skeleton` 只表达正在加载的占位结构。它的尺寸应该接近最终内容，而不是随意堆叠成装饰。

## 何时不用

短暂、不可量化的等待更适合 Spinner。请求失败后必须替换为可恢复的错误状态，不能无限显示骨架屏。

## 可访问性

- Skeleton 默认 `aria-hidden`，不应成为屏幕阅读器中的无意义内容。
- 在其附近提供真实的加载状态文本，或让父区域明确声明忙碌状态。
