`Empty` 用于真正没有内容的状态。它应解释当前为什么为空，并只提供与该状态相关的恢复动作。

## 何时不用

加载中、请求失败或无搜索结果不是同一种空状态；分别使用 Skeleton/Spinner、Alert 或明确的“未找到结果”文案。

## 可访问性

- 标题应描述实际状态，不要只写“没有数据”。
- `action` 必须使用语义按钮或链接，并说明发生什么。
