## 加载状态

`loading` 会禁用原生按钮、设置忙碌状态，并提供“正在加载”的辅助技术提示。不要在加载时保留可重复提交的操作。

## 可访问性

- 原生 `button` 自动支持键盘 Enter 与 Space 触发。
- 图标按钮必须使用 `IconButton` 并传入可读的 `aria-label`。
- 使用 `loading` 时保持按钮文案稳定，避免用户失去操作上下文。
